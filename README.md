# Smart Number Guessing Game 🎯

Welcome to my 3rd official C# project! 

## 📌 Project Overview
This is an interactive console-based game where the computer thinks of a secret number between 1 and 100, and the player tries to guess it. The game provides real-time feedback (Higher/Lower) and tracks the number of attempts.

## 🛠 Features & C# Concepts
- **While Loops:** The heart of the game! It keeps the application running until the correct answer is found.
- **Random Class:** Used to generate a unique secret number every time the game starts.
- **Conditional Logic (If-Else):** Processes the player's guess and provides hints.
- **Counter Logic:** Tracks the player's performance by counting each attempt.
- **User Interaction:** Interactive input handling with `int.Parse` and `Console.ReadLine`.

## 🎮 How to Play
1. The computer picks a number between 1-100.
2. Enter your guess in the console.
3. If your guess is too low, the game says **"Go HIGHER! ⬆️"**.
4. If your guess is too high, it says **"Go LOWER! ⬇️"**.
5. Find the number in the fewest attempts possible to win!
